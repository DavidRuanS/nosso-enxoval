# Nosso Enxoval — David & Bruna

Aplicação web leve e responsiva para organizar o enxoval da casa.

- Itens, categorias e campos personalizados
- Status de compra e valores
- Fotos comprimidas no navegador
- Pesquisa, filtros e indicadores
- Backup e restauração em JSON
- Supabase como banco de dados
- Rotina automática de keep-alive pelo GitHub Actions

A aplicação foi pensada para uso compartilhado por link, sem login.
